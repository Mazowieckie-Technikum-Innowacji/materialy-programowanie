# Materiały do nauki programowania

Krótkie ściągi i instrukcje dla uczniów techników informatycznych i dla każdego, kto zaczyna z Gitem i C#.
Przygotowane w Mazowieckim Technikum Innowacji z myślą o aplikacjach konsolowych i egzaminie zawodowym INF.04.

## Spis

| Plik | O czym jest |
|---|---|
| [csharp-sciaga-string.md](csharp-sciaga-string.md) | metody `string` i `char` w C#: szukanie, wycinanie, dzielenie, wczytywanie i formatowanie |
| [slowniczek.md](slowniczek.md) | słowniczek pojęć z programowania w C#: klasy i obiekty, pętle, tablice, wyjątki, narzędzia, Git (z przykładami kodu) |
| [inf04-lista-kontrolna.md](inf04-lista-kontrolna.md) | lista kontrolna do części praktycznej INF.04: foldery, aplikacja konsolowa i mobilna, dokumentacja, zrzuty ekranu, najczęstsze błędy |
| [git-podstawy.md](git-podstawy.md) | Git i GitHub w pigułce: klonowanie, commit, push, typowe błędy |
| [snippety/](snippety/README.md) | 45 fragmentów kodu (snippetów) do Visual Studio dla aplikacji konsolowych w C#: instrukcja instalacji, spis skrótów i same pliki `.snippet` |

Zaczynasz od zera? Najpierw zajrzyj do przewodnika [csharp-jak-zaczac](https://github.com/Mazowieckie-Technikum-Innowacji/csharp-jak-zaczac): instalacja, pierwszy program, debugowanie.

## Jak korzystać

- Czytaj bezpośrednio na GitHubie albo pobierz repozytorium (**Code → Download ZIP**).
- Przykłady kodu możesz kopiować i zmieniać na własnych ćwiczeniach.
- Ściągi nie zastępują dokumentacji Microsoftu ([docs.microsoft.com](https://learn.microsoft.com/pl-pl/dotnet/csharp/)),
  tylko zbierają to, co najczęściej się przydaje.
